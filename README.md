# ayoreni-docs

This private repo is the shared memory for building Ayoreni: the roadmap, phase briefs and reviews, the API contract, and the current status. It is read by the UI and backend Claude sessions and by the owner.

- `CLAUDE.md`: the rules every session follows.
- `docs/STATUS.md`: where things stand. Read it first.
- `docs/WORKING-AGREEMENT.md`: how the UI and backend sessions coordinate, with starter prompts.
- `docs/contracts/`: `api.md` (owned by the backend) and `ui-needs.md` (owned by the UI).
- `docs/project/ROADMAP.md`: the 33-phase plan.
- `docs/phases/`: phase briefs, reviews, templates, the usage log, and screenshots.
- `docs/architecture/`: ADRs.
- `docs/dev-data/`: the dev environment and synthetic seed guide.
- `docs/design-source/`: the designer's original concept images. These are superseded by the design canvas linked in `STATUS.md`.

Synthetic data only. No keys, account numbers or patient data in this repo.
